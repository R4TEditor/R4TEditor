R4TEditor — Tools
=================

This directory contains scripts to install, run, and build R4TEditor.
Start with setup.sh (Linux/macOS) or setup.bat (Windows) and it will
guide you through everything else.


Quick Start
-----------
Linux / macOS:
    cd tools/linux
    bash setup.sh

Windows:
    Double-click tools\windows\setup.bat
    (or run it from a terminal)


What each script does
---------------------

setup        The main entry point. Asks whether you want to build or run
             the project, whether to enable dev mode, then calls the other
             scripts in the right order automatically.

install_deps Sets up a Python virtual environment at tools/.venv and
             installs all dependencies from requirements.txt.
             Safe to run multiple times — skips steps already done.

launch       Runs R4TEditor normally (production mode).

dev          (Linux only) Runs the backend via uvicorn with --reload so
             the server restarts automatically when you edit source files.
             Set R4T_PORT=9000 to use a different port (default: 8000).

build        Creates a standalone binary in dist/ using PyInstaller.
             On Windows, build.bat also accepts a pypresence hidden-import
             for Discord RPC support.

clean        Removes build/, dist/, and R4TEditor.spec left over from a
             previous PyInstaller build.


Dev mode
--------
When dev mode is enabled (via setup), the version string in
backend/main.py is temporarily changed from e.g. "0.2.0" to "0.2.0-dev".
Running setup again without dev mode will revert it to the base version.
Remember to revert before committing or cutting a release.


Requirements
------------
- Python 3.10 or newer
  Linux:   sudo apt install python3   (Debian/Ubuntu)
           sudo dnf install python3   (Fedora)
  Windows: https://python.org/downloads

- pip (usually bundled with Python)
- PyInstaller is installed automatically when you run build
