# R4TEditor Feature List
> Somone requested that i make a list of things this includes and possible planed things in the future. so here it is.
---

- [ ] Editing Local Files
    - [x] Move and rename files
    - [x] Folder picker dialog
    - [x] File picker dialog
    - [ ] Delete files
    - [ ] Right click context menu (delete, copy, paste, etc.)
- [X] SFTP
    - [X] Connect to remote servers via SFTP
    - [x] Read and write remote files
    - [X] Multiple SFTP connections at the same time
    - [x] Auto upload on save
- [ ] Environment Handling
    - [x] Detect installed Skript version
    - [x] Detect installed addons
    - [x] Warn if Skript version is outdated
    - [ ] Jar to JSON converter for addon syntax
    - [ ] Load addon syntax from local JSON files
- [X] Parser / Linter
    - [x] Validate syntax against loaded Skript docs
    - [x] Flag invalid or unknown syntax
    - [x] Warn on deprecated syntax
    - [x] Suppress warnings with #! ignore
    - [x] Silently skips comments, blank lines, and headers
- [ ] Misc and UI
    - [X] Switch between built-in themes
    - [X] Upload custom theme files
    - [ ] Custom Theme file editor
    - [X] Adjustable font family and size
    - [X] Adjustable line height and tab width
    - [X] Toggle autocomplete
    - [X] Toggle indent guides
    - [X] Toggle minimap
    - [X] Sidebar position (left or right)
    - [X] Script header template
    - [X] Find and replace in current file
    - [X] Find and replace across open files
    - [X] Find and replace across all files and folders
    - [X] Regex, match case, and whole word search options
    - [X] Local and internet connection indicators
    - [X] Small caps translator
    - [X] HTML color code preview
    - [X] Automatic script header on new file
    - [ ] SkriptHub syntax search and docs browser
